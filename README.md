# 姿勢AI分析アプリ 取扱説明書

整骨院での治療前後の姿勢改善・可動域改善を、スマホ・タブレット1台で客観的に計測・比較できるWebアプリです。

---

## 動作環境

| 端末 | ブラウザ |
|---|---|
| iPhone / iPad | Safari |
| Android | Chrome |
| PC | Chrome / Edge |

**インターネット接続が必要です**（AIモデルの読み込みのため）

---

## 起動方法

1. SafariまたはChromeでアプリのURLにアクセスする
2. 「カメラへのアクセスを許可しますか？」が表示されたら **許可** をタップ
3. AIモデルの読み込みが完了すると（数秒）、カメラ画面が起動する

> **カメラが起動しない場合**  
> `設定 > Safari > カメラ` が「許可」になっているか確認してください。  
> 一度「許可しない」を選んだ場合は `設定 > Safari > 詳細 > ウェブサイトごとの設定` から該当URLを削除してください。

---

## 計測モードの選択

画面上部のタブで計測モードを選びます。

| タブ | 撮影方向 | 主な用途 |
|---|---|---|
| **正面** | 患者の正面から | 肩・骨盤の水平差、頭の傾き |
| **横向き** | 患者の真横から | 猫背・反り腰・膝の角度 |
| **動的** | 正面から（静止） | 体幹の安定性・揺らぎの計測 |
| **可動域** | 動作に応じて変わる | 前屈・後屈などの関節可動域 |

---

## 姿勢比較モード（正面・横向き・動的）

### 操作手順

1. タブで計測モードを選ぶ
2. 患者に立ってもらい、**全身が画面に入るように**距離を調整する
3. 骨格（青いライン）が表示され、計測値が安定したら **「治療前を保存する」** をタップ
4. 施術を行う（アプリはそのまま開いておく）
5. 治療前と同じ方向・距離で患者に立ってもらい **「治療後を保存する」** をタップ
6. レポートが表示される

> 治療前を保存するとモードタブがロックされます。前後で同じ条件での比較が保たれます。

### 計測値の見方

#### 正面モード

| 指標 | 説明 | 理想値 |
|---|---|---|
| 頭部前傾角 | 耳・肩・腰の一直線度 | 160°以上 |
| 体幹傾斜角 | 上半身の垂直からのズレ | 5°以下 |
| 肩の水平差 | 左右の肩の高さの差（＋＝左が高い） | ±3%以内 |
| 骨盤の水平差 | 左右の骨盤の高さの差（＋＝左が高い） | ±3%以内 |
| 頭部傾斜角 | 頭の左右への傾き | ±2°以内 |
| 体幹側方傾斜 | 体の重心の左右へのズレ | ±3%以内 |

#### 横向きモード

| 指標 | 説明 | 理想値 |
|---|---|---|
| 骨盤傾斜角 | 前傾（＋）・後傾（−）の角度 | ±5°以内 |
| 耳の垂線ズレ | 足首基準の重心線から耳のズレ | ±5%以内 |
| 肩の垂線ズレ | 足首基準の重心線から肩のズレ | ±5%以内 |
| 膝関節角 | 膝の伸展角度（180°＝完全伸展） | 170°以上 |

#### 動的モード（10秒間静止して計測）

| 指標 | 説明 | 理想値 |
|---|---|---|
| 左右の揺らぎ | 立位時の左右方向のブレ | 2以下 |
| 前後の揺らぎ | 立位時の前後方向のブレ | 2以下 |
| 安定性 | 総合的な体幹安定スコア | 80pt以上 |

## 可動域（ROM）計測モード

治療前後の関節可動域（Range of Motion）をピーク角度で比較します。

### 操作手順

1. **「可動域」タブ**をタップ
2. 横スクロールで**動作を選択**する
3. 撮影ヒントに従い、カメラの向きを合わせる
4. **「▶ 計測開始」**をタップ → 赤い録画インジケーターが点滅
5. 患者にゆっくり最大まで動作してもらう
6. **「⏹ 計測終了」**をタップ → ピーク角度が確定・表示される
7. **「治療前として保存する」**をタップ
8. 施術を行う
9. 同じ動作で手順4〜6を繰り返す
10. **「治療後として保存する」**をタップ → レポートが表示される

> 治療前を保存すると動作の選択とモードタブがロックされます。前後で同じ動作での比較が保たれます。

### 計測できる動作

| 動作 | 撮影方向 | 正常可動域 |
|---|---|---|
| 前屈 | 横向き | 90° |
| 後屈 | 横向き | 30° |
| 側屈（左） | 正面 | 30° |
| 側屈（右） | 正面 | 30° |
| 頸部前屈 | 横向き | 60° |
| 頸部後屈 | 横向き | 50° |

### レポートの見方

- **ピーク角度**：計測中の最大角度（大きいほど可動域が広い）
- **正常可動域比**：正常値を100%としたときの割合（100%以上が理想）
- 変化欄の**緑**＝改善（角度が増加）、**赤**＝低下

## 撮影のコツ

- **距離**：患者の全身（頭〜足首）が画面に収まる距離
- **高さ**：カメラを腰〜みぞおちの高さに固定すると安定
- **背景**：単色・明るい壁を背景にすると骨格検出の精度が上がる
- **服装**：体のラインが出やすい服が望ましい
- **前後の統一**：治療前後でなるべく同じ位置・距離・方向で撮影する
- **可動域計測**：ゆっくり動いてもらうと精度が上がる

## よくある質問

**Q. 骨格（青いライン）が表示されない**  
A. 全身がカメラに映っているか確認してください。背景が複雑な場合は単色の壁の前に立ってもらうと改善することがあります。

**Q. 計測値がチラつく・安定しない**  
A. 値は4フレームの平均で更新されています。患者に静止してもらい、2〜3秒待つと安定します。

**Q. 動的モードで値が出ない**  
A. 骨格が検出された状態で約10秒間静止してください。データが蓄積されると自動的に表示されます。

**Q. 可動域計測で「計測開始」後にピーク角度が更新されない**  
A. 患者が最大まで動作しきれていない可能性があります。骨格の青いラインが表示されていることを確認し、ゆっくり動作してもらってください。

**Q. 治療前後で計測モードや動作を変えられますか？**  
A. 治療前を保存するとモードと動作がロックされます。別の条件で測定したい場合は「もう一度測定する」でリセットしてください。
